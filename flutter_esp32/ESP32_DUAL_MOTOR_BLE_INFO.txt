🎮 FLUTTER COMMAND REFERENCE
=============================

📝 INDIVIDUAL MOTOR COMMANDS (3-byte format: [command, param_low, param_high])
------------------------------------------------------------------------------
Use with Motor1 Command or Motor2 Command characteristics:

0x00 - STOP        | Parameter: 0        | Stop motor movement
0x01 - MOVE_ABS    | Parameter: position | Move to absolute position (int16)
0x02 - MOVE_REL    | Parameter: steps    | Move relative steps (int16, negative OK)
0x03 - HOME        | Parameter: 0        | Home the motor (find sensor)
0x04 - SET_SPEED   | Parameter: delay_ms | Set step delay (1-1000ms)
0x05 - ENABLE      | Parameter: 0        | Enable motor driver
0x06 - DISABLE     | Parameter: 0        | Disable motor driver
0x07 - CALIBRATE   | Parameter: 0        | 30-second LEFT movement for manual homing

📝 DUAL MOTOR COMMANDS (3-byte format: [command, param_low, param_high])
------------------------------------------------------------------------
Use with System Service Dual Command characteristic:

0x10 - STOP_ALL        | Parameter: 0        | Stop both motors immediately
0x11 - HOME_ALL        | Parameter: 0        | Home both motors in sequence
0x12 - SYNC_MOVE       | Parameter: position | Both motors to same position
0x13 - PARALLEL_MOVE   | Parameter: steps    | Both motors same direction
0x14 - MIRROR_MOVE     | Parameter: steps    | Motors opposite directions
0x15 - SEQUENCE_MOVE   | Parameter: motor_id | Move motors sequentially
0x16 - CALIBRATE_ALL   | Parameter: 0        | 30-second LEFT movement both
0x17 - ENABLE_ALL      | Parameter: 0        | Enable both motor drivers
0x18 - DISABLE_ALL     | Parameter: 0        | Disable both motor drivers

📊 STATUS RESPONSES
===================

🔍 MOTOR STATUS (4-byte response from Status characteristics):
[status, pos_low, pos_high, fault]

Status Values:
• 0 = IDLE     | Motor is idle/stopped
• 1 = MOVING   | Motor is moving
• 2 = ERROR    | Motor fault detected
• 3 = DISABLED | Motor driver disabled

Position: 16-bit value (pos_high << 8 | pos_low)
Fault: 0=OK, 1=Hardware fault detected

🔍 SYSTEM STATUS (8-byte response from System Status characteristic):
[sys_status, sync_mode, m1_status, m1_pos_low, m1_pos_high, m2_status, m2_pos_low, m2_pos_high]

System Status Values:
• 0 = INIT     | System initializing
• 1 = READY    | System ready for commands
• 2 = RUNNING  | System executing commands
• 3 = ERROR    | System error state
• 4 = TESTING  | System in test mode

Sync Mode Values:
• 0 = INDEPENDENT  | Motors work independently
• 1 = PARALLEL     | Motors move together same direction
• 2 = MIRRORED     | Motors move opposite directions
• 3 = COORDINATED  | Motors coordinate movements
• 4 = SEQUENTIAL   | Motors move one after another

```dart
import 'package:flutter_blue_plus/flutter_blue_plus.dart';

// 1. Scan for device
await FlutterBluePlus.startScan(timeout: Duration(seconds: 15));

FlutterBluePlus.scanResults.listen((results) {
  for (ScanResult r in results) {
    if (r.device.platformName == 'ESP32S3_DualMotor') {
      // Found device - connect
      r.device.connect();
      break;
    }
  }
});

// 2. Discover services
List<BluetoothService> services = await device.discoverServices();

// 3. Find characteristics
BluetoothCharacteristic? motor1CommandChar;
BluetoothCharacteristic? motor2CommandChar;
BluetoothCharacteristic? dualCommandChar;
BluetoothCharacteristic? motor1StatusChar;
BluetoothCharacteristic? motor2StatusChar;
BluetoothCharacteristic? systemStatusChar;

for (BluetoothService service in services) {
  String serviceUuid = service.uuid.toString();
  
  if (serviceUuid.contains('cde1')) {  // Motor 1 Service
    for (BluetoothCharacteristic char in service.characteristics) {
      if (char.uuid.toString().contains('cd12')) {
        motor1CommandChar = char;  // Motor1 Command
      } else if (char.uuid.toString().contains('cd13')) {
        motor1StatusChar = char;   // Motor1 Status
      }
    }
  } else if (serviceUuid.contains('cde2')) {  // Motor 2 Service
    for (BluetoothCharacteristic char in service.characteristics) {
      if (char.uuid.toString().contains('cd22')) {
        motor2CommandChar = char;  // Motor2 Command
      } else if (char.uuid.toString().contains('cd23')) {
        motor2StatusChar = char;   // Motor2 Status
      }
    }
  } else if (serviceUuid.contains('cde0')) {  // System Service
    for (BluetoothCharacteristic char in service.characteristics) {
      if (char.uuid.toString().contains('cd01')) {
        dualCommandChar = char;    // Dual Command
      } else if (char.uuid.toString().contains('cd03')) {
        systemStatusChar = char;   // System Status
      }
    }
  }
}
```

📤 SENDING COMMANDS:
```dart
// Helper function to send 3-byte commands
Future<void> sendCommand(BluetoothCharacteristic? char, int cmd, int param) async {
  if (char == null) return;
  List<int> bytes = [cmd & 0xFF, param & 0xFF, (param >> 8) & 0xFF];
  await char.write(bytes);
}

// INDIVIDUAL MOTOR EXAMPLES:
await sendCommand(motor1CommandChar, 0x05, 0);      // Enable Motor1
```

```dart
// Enable notifications for status updates
await motor1StatusChar?.setNotifyValue(true);
await motor2StatusChar?.setNotifyValue(true);
await systemStatusChar?.setNotifyValue(true);

// Listen for Motor1 status
motor1StatusChar?.lastValueStream.listen((value) {
  if (value.length >= 4) {
    int status = value[0];
    int position = (value[2] << 8) | value[1];
    bool fault = value[3] != 0;
    print('Motor1 - Status: $status, Position: $position, Fault: $fault');
  }
});

// Listen for Motor2 status
motor2StatusChar?.lastValueStream.listen((value) {

    bool fault = value[3] != 0;
    print('Motor2 - Status: $status, Position: $position, Fault: $fault');
  }

// Listen for System status
```
